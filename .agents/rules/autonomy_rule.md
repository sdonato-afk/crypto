# Autonomía en Investigación, Planificación y Lectura

- **Permiso de Auto-Proceed para Análisis e Investigación**: Cuando la tarea del usuario consista en analizar, planificar, investigar, explorar logs o inspeccionar el proyecto, el asistente tiene permiso total para ejecutar de manera autónoma (auto-proceed) las búsquedas y lecturas de archivos necesarias sin pedir confirmación.
- **Confirmación para Programación y Cambios de Código**: El asistente solicitará confirmación o aprobación explícita al usuario ÚNICAMENTE cuando se trate de programar, editar o aplicar modificaciones a los sistemas, código fuente o programas.
