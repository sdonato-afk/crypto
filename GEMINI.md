# Reglas de Autonomía y Conducta

- **Permiso de Auto-Proceed para Análisis e Investigación**: Cuando la tarea del usuario consista en analizar, planificar, investigar, explorar logs o inspeccionar la base de código, el asistente tiene permiso total para actuar autónomamente (auto-proceed) y leer cualquier archivo o ejecutar búsquedas necesarias sin pedir confirmación.
- **Confirmación Obligatoria para Modificar Código**: El asistente solicitará confirmación o aprobación explícita al usuario ÚNICAMENTE cuando vayamos a programar, editar o aplicar cambios en el código fuente, archivos del sistema o programas.
